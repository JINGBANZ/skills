# 中国癌症筛查指南（中文版）

> 本文是 [`SKILL.md`](./SKILL.md) 的中文对照版本，内容、数字、结构完全一致。英文版为该 skill 的入口（供 agent 按 `description` 匹配触发）；中文版供中文读者与生成中文输出的 agent 直接参考。两版若有出入，以更新较晚者为准，请同步修订。

## 概述

本 skill 把当前（2025–2026）中国癌症筛查指南提炼为一套可供 LLM 套用到用户档案上的规则。它回答的核心问题是：**针对这个人，眼下哪些癌症值得给出筛查建议、用什么检查、多久一次、紧迫程度如何（按中国指南）？**

**核心原则：中国的筛查是「风险分层」而非「按年龄一刀切」。** 核心概念是 **高危人群** —— 对大多数癌症，指南都明确定义了高危标准（感染状态、地理高发区、家族史、暴露因素、量化风险评分），筛查主要面向符合这些标准的人。这源于中国的流行病学特征（高 HBV、高幽门螺杆菌、食管/胃癌的地理高发带）以及有限的内镜资源。因此要问的通常是 **「这个人是否符合高危人群定义？」**，而不是「他是否到了起始年龄？」

**与美国的主要差异（套用这些直觉）：**
- **上消化道癌症（胃癌、食管癌、肝癌）会被主动筛查**，约从 40–45 岁起 —— 在中国高发，且有组织化项目。
- **肝癌筛查以 HBV 为中心**（中国最主要病因），对无肝硬化的 HBV 携带者从 40 岁起即筛查。
- **乳腺癌筛查倚重超声**（中国女性乳腺更致密），常与钼靶并列为主要手段。
- **前列腺癌筛查起始更晚**（一般约 60 岁）—— 发病率较低。
- **筛查资格常使用量化风险评分**（胃癌评分、结直肠癌问卷、肝癌 aMAP）。

**来源层级：** 国家癌症中心（NCC）指南（《中国…筛查与早诊早治指南》）、国家卫健委（NHC）方案（2024 版：肺癌/结直肠癌/胃癌/食管癌）、中国抗癌协会（CACA）整合指南。通过以下国家项目落地：**城市癌症早诊早治项目**（肺、结直肠、上消化道、乳腺、肝）、农村高发区早诊早治项目（食管/胃/肝）、**两癌筛查**妇女项目（宫颈+乳腺，35–64 岁）。

## 如何读取用户档案

| 信号 | 提取要点 |
|---|---|
| `age`、`biological_sex` | 是门槛，但次于高危状态 |
| `smoking` | 状态 + **包年**；中国肺癌标准中**被动吸烟**暴露同样计入 |
| `alcohol` | 大量饮酒 —— 食管/肝脏的风险因素（合并烫食、吸烟时尤甚） |
| BMI | 超重/肥胖 —— 结直肠与胃癌评分的输入项 |
| `family_cancer_history` | 每位亲属：癌种 + 亲缘等级 + 诊断年龄。**一级亲属家族史几乎是中国所有消化道癌症的高危触发条件** |
| `past_medical_history` | **慢性萎缩性胃炎、胃黏膜肠上皮化生、胃溃疡/息肉、恶性贫血、肝硬化、MAFLD/脂肪肝、炎症性肠病、既往癌症、林奇综合征/FAP** |
| `hep_b_c_status` | **慢性 HBV 或 HCV → 中国肝癌筛查的核心触发条件** |
| `occupational_exposure` | 氡/石棉/砷/铬（肺），芳香胺（膀胱） |
| `sun_reaction` | 次要 —— 皮肤癌在中国人群中发病率低 |
| `red_flag_symptoms` | 绝不遗漏 —— 每一项都要给出安全提示 |
| `hpv_vaccinated`、`last_pap_result` | 宫颈病史 |
| `hrt`、`parity`、`ever_breastfed`、`menopause_status` | 乳腺/子宫内膜的生殖背景 |
| **地区 / 籍贯**（若已知） | 居住在**高发区**是食管/胃/鼻咽癌的正式触发条件 —— 可从 `occupational_exposure`/自由文本推断；否则视为未知 |

若某字段被拒答或未知，不要臆测 —— 基于已知信息给建议，并注明缺口。**HBV/HCV 状态、幽门螺杆菌、家族史是中国框架中收益最高的字段**，缺失时应提示。

## 决策流程

1. **先查感染 + 家族史触发条件**（HBV/HCV → 肝；幽门螺杆菌/癌前病变/一级亲属 → 胃；一级亲属 → 结直肠/食管）。在中国，这些比年龄更能驱动筛查。
2. **套用各癌种的高危人群定义**；若符合，推荐相应的针对性筛查。
3. **套用量化风险评分**（胃癌评分、结直肠问卷、肝癌 aMAP 分层）以确定间隔。
4. **按年龄套用妇女项目**（宫颈 + 乳腺）。
5. **逐一处理每个预警症状**，给出以行动为先的提示。
6. **赋予严重度**与**科室**。

## 严重度映射

FixYou 把严重度映射为分值（high=30，medium=20，low=10）：
- **high** —— 明确符合某高危人群定义且有活跃项目（HBV 携带者 → 肝；幽门螺杆菌 + 萎缩性胃炎 → 胃；胃癌评分高；一级亲属患消化道癌使起始年龄提前）且筛查到期。
- **medium** —— 按年龄适用的常规项目筛查（如 45–70 岁女性的乳腺；处于结直肠高危问卷范围内的成人）。
- **low** —— 临界/共同决策（前列腺 PSA；接近但未达高危阈值；甲状腺等中国持中立态度者）。

## 高发癌症（中国主动筛查）

### 肝癌 / Liver (HCC)
- **高危人群：** 慢性肝病或遗传风险，**尤其年龄＞40 岁的男性**（《原发性肝癌诊疗指南 2024》原文："尤其年龄＞40岁的男性"；2021 早筛专家共识将目标人群表述为 40–75 岁男性），具备以下任一：**HBV 和/或 HCV 感染**、肝硬化（任何病因）、大量饮酒、**MAFLD/脂肪肝**、黄曲霉毒素 B1 暴露、或肝癌家族史。**无肝硬化的慢性 HBV 携带者也纳入筛查** —— 这是中国与美国的标志性差异。
- **检查 / 间隔：** **腹部超声 + 血清 AFP，至少每 6 个月**一次（诊疗指南 2024）。**AFP-L3** 与 **异常凝血酶原（DCP/PIVKA-II）** 是指南列出的补充早期标志物（GALAD 模型联合应用）；更高风险分层加增强 MRI。
- **风险分层：** **aMAP 评分为 3 级** —— 低风险（0–50）、中风险（50–60）、高风险（60–100）（见诊疗指南）。各级的**监测间隔**来自 **2021 中国肝癌早筛策略专家共识 / 二级预防指南**（并非 aMAP 评分本身）：低危 → 每年超声+AFP；中危 → 每 6 个月；高危 → 每 3–6 个月（+ MRI 每 6 个月）；另有**极高危**类别 → 超声+AFP **每 3 个月** + MRI 每 6 个月。
- **档案钩子：** `hep_b_c_status` = 慢性 HBV/HCV 即为**高严重度**触发条件。
- **来源：** 《原发性肝癌诊疗指南（2024 版）》国家卫健委；《中国肝癌早筛策略专家共识（2021）》（aMAP 分层与间隔）。**科室：肝病科 / 感染科。**

### 胃癌 / Gastric
- **高危人群：** **年龄 ≥45 岁**，且具备以下任一：居住于**胃癌高发区**；**幽门螺杆菌感染**；癌前状态（**慢性萎缩性胃炎、胃黏膜肠上皮化生、胃溃疡/息肉、残胃、恶性贫血**）；**一级亲属患胃癌**；高盐/腌制饮食、吸烟、大量饮酒。
- **检查：** **胃镜**为金标准；幽门螺杆菌优先用尿素呼气试验检测。
- **风险评分（新型胃癌筛查评分系统，0–23 分）：** 输入 = 年龄、性别、**幽门螺杆菌抗体、PGI/PGII 比值（胃蛋白酶原）、胃泌素-17**。高危（17–23）→ 胃镜**每年**；中危（12–16）→ **每 2 年**；低危（0–11）→ **每 3 年**。（单用血清胃蛋白酶原不能作为独立筛查手段。）
- **档案钩子：** `past_medical_history` 中的萎缩性胃炎/肠上皮化生/恶性贫血，或一级亲属胃癌 → 高严重度。
- **来源：** 《中国胃癌筛查与早诊早治指南（2022）》NCC；NHC 2024 方案。**科室：消化内科。**

### 食管癌 / Esophageal（鳞癌）
- **高危人群：** **年龄 ≥45 岁**，且具备以下任一：居住于**食管癌高发区**（年龄标化发病率 >15/10 万 —— 河南/河北/山西等农村高发带）；**一级家族史**；食管癌前病变；生活方式风险（**吸烟、饮酒、过烫食物/饮品、腌制食物、口腔卫生差**、既往头颈/上消化道鳞癌）。
- **检查 / 间隔：** **内镜**联合 **卢戈氏碘染色（碘染色）**或 **NBI（窄带成像）**—— 首选手段。**45 岁起始，约 75 岁终止。** 高危 → **每 5 年**；低级别上皮内瘤变 → 每 1–3 年。
- **说明：** 中国针对**鳞状细胞癌**（与美国的 Barrett's/腺癌模型截然不同）。地理 + 家族史是主导触发条件。
- **来源：** 《中国食管癌筛查与早诊早治指南（2022）》NCC；NHC 2024 方案。**科室：消化内科。**

### 肺癌 / Lung
- **高危人群（依据 NHC 2024 方案）：** **年龄 50–74 岁**，且具备以下 **≥1** 项：**吸烟 ≥20 包年**（含曾经吸烟≥20包年但**戒烟不足 15 年**者）；**被动吸烟 ≥20 年**（与吸烟者共同生活或同室工作）；**慢性阻塞性肺疾病（COPD）**；**职业致癌物暴露至少 1 年**（石棉、氡、铍、铬、镉、镍、硅、煤烟及煤烟尘等）；**一级亲属确诊肺癌**（单独即可成立）。
- **检查 / 间隔：** **低剂量螺旋 CT（LDCT），原则上每年一次**。结节阳性/不确定者缩短间隔（如 ≥6 mm → 3 个月复查）。
- **中国关键差异：** 非吸烟路径很重要（被动吸烟、COPD、职业暴露、家族史）—— 中国非吸烟者肺癌负担高，因此不要仅凭个人包年来把关。（≥20 包年 + 戒烟<15 年这一阈值本身与美国 USPSTF 一致。）
- **来源：** 《肺癌筛查与早诊早治方案（2024年版）》国家卫健委（现行权威方案）。**科室：呼吸科 / 胸外科。**

### 结直肠癌 / Colorectal
- **高危人群（两条路径）：**
  - **散发性（依据 NHC 2024 方案）：** 风险问卷对年龄（≤49=0、50–59=1、≥60=2）、性别（男=1）、**一级亲属患结直肠癌**（=1；但单个 <60 岁一级亲属或 ≥2 名一级亲属直接计 4 分）、吸烟（=1）、BMI≥23（=1）评分 → **累计 ≥4 分 = 高危**。筛查窗口 **40–74 岁**。（2020 NCC 指南刻意不设数值阈值，仅依同样的因素定性判定高危；≥4 分方案是 2024 方案的操作化。）
  - **遗传性：** **林奇综合征**（MLH1/MSH2 → 20–25 岁起肠镜；MSH6/PMS2 → 30–35 岁起）/**家族性腺瘤性息肉病（FAP）**（10 岁起每年肠镜）→ 单独的强化监测。
- **检查 / 间隔：** **结肠镜**为一线，**每 5–10 年**（正常 → 最长 10 年后复查）；**每年便潜血（FIT）**。拒绝结肠镜者的替代：乙状结肠镜、结肠 CT 成像、**多靶点粪便 DNA**。
- **中国关键差异：** 从 **40 岁**起始，但**仅对问卷识别出的高危人群筛查**（风险分层，而非全人群）—— 反映内镜资源限制。
- **来源：** 《结直肠癌筛查与早诊早治方案（2024年版）》国家卫健委（≥4 分问卷、40–74 岁）；《中国结直肠癌筛查与早诊早治指南（2020）》NCC（检查方法、遗传性监测）。**科室：消化内科 / 肛肠科。**

## 妇女项目癌症

### 乳腺癌 / Breast
- **一般风险：** 女性，**45–70 岁**，**每 1～2 年**筛查 1 次。T/CPMA 014-2020 标准以**乳腺超声为首选手段**（不具备超声条件时才用乳腺 X 线/钼靶）；NCC 2021 指南对**致密型乳腺推荐钼靶联合超声**（中国女性乳腺多致密）。
- **高危人群：** 一级亲属患乳腺/卵巢癌；≥2 名二级亲属在 50 岁前患乳腺/卵巢癌；**BRCA1/2** 携带；30 岁前胸部放疗；模型评估风险升高 → **从 40 岁起始**，**每年**筛查（超声 + 钼靶），必要时加 **MRI**。
- **国家两癌项目：** 为 **35–64 岁**女性提供临床查体 + 超声 + 钼靶。
- **来源：** 《中国女性乳腺癌筛查与早诊早治指南（2021）》NCC；CACA。**科室：乳腺外科 / 乳腺科。**

### 宫颈癌 / Cervical
- **一般风险：** 女性，**25 岁起始，65 岁终止**（若既往筛查充分阴性）。**高危型 HPV 检测每 5 年**（首选）· 联合检测每 5 年 · **TCT/细胞学每 3 年**。异常 → 阴道镜。
- **高危人群：** HIV 阳性/免疫抑制、既往 CIN2+、DES 暴露 → 提前起始、更频繁筛查、65 岁后继续。**HPV 疫苗接种状态不改变筛查方案。** <25 岁一般不筛查。
- **国家两癌项目：** 为 **35–64 岁**女性提供妇科查体 + 细胞学 + 阴道镜，3 年一周期，优先覆盖农村/无业妇女。多省为适龄少女补贴 HPV 疫苗。
- **来源：** 《中国子宫颈癌筛查指南（2023）》；与加速消除宫颈癌行动一致。**科室：妇科。**

## 较低优先级 / 无人群筛查

### 前列腺癌 / Prostate
- **一般风险：** 男性，**约 60 岁起始**，基线 **PSA，之后每 2 年**（预期寿命 >10 年者）（机会性/共同决策，并非全民项目）。
- **高危人群：** 年龄≥45 岁且有**前列腺癌家族史** → **45 岁**起测 PSA；**BRCA2** 携带且年龄≥40 → 约 **40 岁**起。
- **说明：** 起始晚于美国（发病率较低）。**科室：泌尿外科。** 严重度 low/medium。

### 鼻咽癌 / Nasopharyngeal（区域性重点 —— 无美国对应）
- **高危人群：** **华南高发区**居民（广东/广西/福建/湖南/海南），约 30–69 岁，尤其有家族史或 EBV 高危标志者。
- **检查：** **EBV 血清学（VCA-IgA / EBNA1-IgA）和/或血浆 EBV-DNA**；阳性 → 鼻咽镜 + 头颈 MRI。高危人群中通常每年一次。
- **来源：** NCC / 中山大学肿瘤防治中心区域项目。**科室：耳鼻喉科 / 头颈外科。** 仅在有地区/家族触发条件时推荐。

### 甲状腺癌 / Thyroid
- **无人群筛查推荐** —— 中国因**过度诊断**顾虑持中立态度（发病率上升、死亡率持平）。与美国一致（不推荐对无症状成人筛查）。
- **仅限高危：** 儿童期/颈部放疗、家族史/遗传综合征（MEN2、RET、FAP）、或已知结节 → 颈部超声 + **TI-RADS**；可疑 → 细针穿刺活检。**科室：甲状腺外科 / 内分泌科。**

### 无中国人群筛查的癌症（仅高危/监测）
以下所有癌症：**无人群筛查推荐** —— 仅在有明确高危触发条件时推荐；否则引导至症状警觉。
- **皮肤癌 / Skin：** 中国人群发病率低；仅对白化病、着色性干皮病、慢性溃疡/瘢痕进行监测。**科室：皮肤科。**
- **口腔癌 / Oral：** 对**嚼槟榔者**（湖南/海南突出）、重度烟酒者、口腔白斑进行机会性检查。**科室：口腔科。**
- **卵巢癌 / Ovarian：** 不筛查（CA-125+经阴道超声无死亡率获益）。高危 = BRCA1/2、林奇综合征 → 监测 + 降风险手术咨询。**科室：妇科 / 遗传咨询。**
- **胰腺癌 / Pancreatic：** 不筛查。高危 = 家族性 / BRCA2/PALB2/CDKN2A/林奇/黑斑息肉综合征 → 在专科中心行 MRI/MRCP ± 超声内镜。**科室：消化内科。**
- **膀胱癌 / Bladder：** 不筛查。职业芳香胺暴露 + 重度吸烟 → 仅在职业健康场景行尿细胞学 ± 膀胱镜。血尿 → 进一步检查。**科室：泌尿外科。**
- **肾癌 / Kidney：** 不筛查；多为偶然发现。遗传性（VHL、BHD）→ 定期影像。**科室：泌尿外科。**
- **子宫内膜癌 / Endometrial：** 不筛查。林奇/肥胖/多囊卵巢综合征/无拮抗雌激素 → 内膜取样 ± 经阴道超声。**绝经后出血 → 立即评估。科室：妇科。**
- **睾丸癌 / Testicular：** 不筛查（罕见）。隐睾病史 → 自我警觉/查体。**科室：泌尿外科。**

## 预警症状（独立于筛查）

每个上报的症状都要给出以**行动为先**的安全提示；绝不遗漏。

| 症状 | 主要关注癌种 | 行动要点 |
|---|---|---|
| `blood_in_stool` | 结直肠 | 1–2 周内消化内科 / 结肠镜；大量出血则急诊 |
| `blood_in_urine` | 膀胱 | 泌尿外科 + 膀胱镜；任何肉眼血尿需尽快检查 |
| `persistent_cough` | 肺 | 尽快影像 + 呼吸科；咯血则急诊 |
| `unexplained_weight_loss` | 消化道/肺/胰腺 | 数周内开始检查 |
| `new_lump` | 按部位：乳腺/睾丸/淋巴 | 尽快查体 + 影像 |
| `changing_skin_lesion` | 黑色素瘤 | 皮肤科评估 |
| `persistent_abdominal_pain` | 消化道/胰腺/卵巢 | 消化内科评估 |
| `dysphagia_hoarseness` | **食管**（中国高发） | 持续 >2–3 周则消化内科内镜 |
| `postmenopausal_bleeding` | 子宫内膜 | 尽快妇科 + 内膜评估 |

症状预警是引导就医的信号，不是诊断。中国语境提示：吞咽困难与上消化道症状因食管/胃癌发病率高而具有更高先验概率 —— 应视为高收益信号。

## 护栏

- **以高危人群状态为先：** 在中国，「是否符合高危定义」比年龄更能驱动建议。缺失高收益字段时应提示（**HBV/HCV、幽门螺杆菌、家族史、地区**）。
- **对 HBV/HCV 携带者筛查肝癌、对幽门螺杆菌/癌前病变携带者筛查胃癌** —— 这是中国的标志性筛查；不要因套用美国直觉而漏掉。
- **把超声当作真正的筛查手段**（肝、致密乳腺、甲状腺结节）—— 它是中国实践的核心，而非仅辅助。
- 不要推荐中国在人群层面不推荐的筛查（甲状腺、卵巢、胰腺、皮肤、口腔、膀胱、肾、睾丸、子宫内膜）—— 须有高危触发条件。
- 不要臆造档案中没有的地区、感染或家族史。地区未知时，注明高发区相关癌症（食管/胃/鼻咽）可能需在补充信息后细化。
- 区分**筛查**（无症状）与**诊断性检查**（有症状）。

## 速查

- **约 40–45 岁起主动筛查：** 肝（HBV/HCV/肝硬化，超声+AFP 每 6 个月）、胃（≥45 + 幽门螺杆菌/癌前病变/一级亲属，按评分行胃镜）、食管（≥45 + 地区/一级亲属/生活方式，碘染色内镜）、结直肠（≥40，问卷 ≥4 → 结肠镜/FIT）、肺（50–74，≥20 包年/戒烟<15 年 或 被动/COPD/职业/家族）。
- **妇女项目（35–64 岁）：** 宫颈（HPV 每 5 年 / TCT 每 3 年，25–65）+ 乳腺（**超声** ± 钼靶，45–70，每 1～2 年）。
- **较晚/机会性：** 前列腺（约 60，PSA 每 2 年）、鼻咽（仅高发区 EBV）。
- **无人群筛查（仅高危）：** 甲状腺、皮肤、口腔、卵巢、胰腺、膀胱、肾、子宫内膜、睾丸。
- **中国标志性触发条件：** 慢性 **HBV/HCV** → 肝 · **幽门螺杆菌** + 萎缩性胃炎 → 胃 · **高发区** + 一级亲属 → 食管/胃/鼻咽。
- **每个预警症状 → 一条以行动为先的提示。** 绝不遗漏。
